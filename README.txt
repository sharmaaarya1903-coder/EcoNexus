ECONEXUS SERVER CONNECTION KIT

1. Install Node.js LTS on the PC if Node.js is not already installed.
2. Open the server folder.
3. Double-click start-econexus.bat.
4. Keep that black server window open while using the app.
5. The Android app config is already set for:
   http://192.168.29.217:3000
6. Phone and PC must be on the same Wi-Fi for this local setup.
7. Test from the phone browser:
   http://192.168.29.217:3000/api/health
8. If it says ok:true, the connection works.
